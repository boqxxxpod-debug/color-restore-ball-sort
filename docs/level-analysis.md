## Interpretation

Difficulty is a relative 0–100 engineering score combining exact shortest length when exhaustive (otherwise certificate length, at 0.8/move), color count (3.2/color), branching on the certified route, alternative legal moves, empty-tube usage, and a 12-point workspace-scarcity premium for one-buffer boards. Forced moves and moves that dismantle an already completed tube reduce the score. The JSON companion contains every component, including forced-move ratio, alternative moves per step, empty-tube dependency, maximum/average branching, and terminal dead ends.

When the graph is exhausted, breadth-first traversal proves the shortest distance and terminal dead-end count for the complete normalized reachable graph. If a future level hits the state cap, these become bounded observations. Large exploration remains in this development-only Node tool and is never loaded by the browser.
